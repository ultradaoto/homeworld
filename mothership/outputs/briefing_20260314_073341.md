## SECTION 3 — FIELD PATTERNS (CONFIRMED SIGNALS)

**1. Protocol Standardisation is Underway**
CrewAI's adoption of MCP (Model Context Protocol) as its tool interface standard — rather than a proprietary plugin system — indicates the broader field is converging on open protocols. Frameworks that resist this will accrue integration debt.

**2. Documentation Instability = API Instability Risk**
Both LangGraph and AutoGen have recently migrated documentation homes. This is not coincidence — it correlates with rapid organisational scaling and probable API surface changes. Factor version-lock strategy into any build decision.

**3. Role-Based Decomposition is the Dominant Mental Model**
CrewAI's team-mirroring architecture (agents as specialists, crews as coordinating units) is intuitive and maps cleanly onto business process design. Whether this model outperforms graph-state or actor-model approaches for complex dynamic tasks remains unverified.
